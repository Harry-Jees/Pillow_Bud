# Code of Conduct

## Our commitment

Pillow Bud is intended to support emotional well-being. We want the project community to be welcoming, constructive, and safe for people of all backgrounds, identities, experience levels, and viewpoints.

## Expected behavior

- Be respectful, patient, and constructive.
- Critique ideas, behavior, and code—not a person's identity or worth.
- Welcome good-faith questions and explain disagreements without insults.
- Respect boundaries and accept that people may decline a discussion.
- Protect privacy. Never publish private chats, journal entries, mood notes, personal identifiers, credentials, keys, or other sensitive information.
- Discuss mental-health and crisis-safety issues carefully. Avoid sensationalism, shaming, graphic detail, and unsupported clinical claims.
- Report security concerns privately using the process in [SECURITY.md](SECURITY.md).

## Unacceptable behavior

Examples include harassment, threats, discrimination, intimidation, stalking, doxxing, unwanted sexual attention, repeated personal attacks, deliberate disruption, publishing private information, and encouraging harm.

## Scope

This code applies to project spaces, including issues, pull requests, code reviews, discussions, and other community spaces when someone is representing the project.

## Enforcement

Project maintainers may edit or remove harmful content, close discussions, reject contributions, or restrict participation when necessary. Enforcement decisions should be proportionate to the behavior and may include a warning or temporary/permanent exclusion.

To report a conduct concern, contact the repository maintainer privately through GitHub rather than starting a public argument. For a security vulnerability, follow [SECURITY.md](SECURITY.md). Reports will be handled discreetly where reasonably possible; do not include sensitive personal data unless it is essential.

This policy is inspired by the Contributor Covenant community standard. It is maintained for this repository and may be updated as the project evolves.
